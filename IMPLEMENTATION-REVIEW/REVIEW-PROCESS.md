# Review Process

## Phase 1 — Read

Reviewer reads the repository overview and the relevant engine specifications.

## Phase 2 — Scope

Reviewer selects one or more technical areas and records the exact documents reviewed.

## Phase 3 — Findings

Each finding should identify:

1. specification reference;
2. observed requirement or statement;
3. ambiguity, inconsistency, risk, or missing definition;
4. technical consequence;
5. proposed specification clarification, if appropriate.

## Phase 4 — Independent implementation test

Where practical, two independent implementations should be compared against the same deterministic test vectors.

## Phase 5 — Resolution

Accepted changes are incorporated into the formal specification through documented revisions.

Rejected or deferred findings should remain traceable where they materially affect implementation.

## Phase 6 — Readiness

Implementation readiness should be evaluated separately for each engine and for the integrated protocol.

## Independence

A reviewer may participate without becoming an implementer, maintainer, collaborator, or protocol governance participant.
