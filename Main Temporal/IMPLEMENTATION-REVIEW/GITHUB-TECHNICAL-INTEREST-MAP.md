## Priority for manual verification

Before any direct mention or outreach, verify each account manually and record:

- whether the account is an individual or organization;
- whether the project is active;
- whether the technical work is authored or maintained by the account;
- current contact/review channel;
- whether the account publicly welcomes collaboration;
- the exact CPG Engine or specification that matches the expertise.

## Outreach rule

Do not state that a candidate is interested in CPG until they explicitly demonstrate interest.

The correct language is:

> "Your public work on [project/topic] appears technically relevant to [CPG area]. We would like to invite you to independently review Chain Poker Genesis by LAEV."
