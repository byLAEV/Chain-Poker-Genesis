# Graphical Interface Engine — Versioning Policy

**Current documented version:** 1.0

## Version 1.0

The historical v1.0 specification establishes the initial graphical interface structure and its principal access points.

## Version Independence

The Graphical Interface Engine is designed to evolve independently from the poker-table logic and other protocol engines.

Potential future changes include:

- visual improvements;
- navigation improvements;
- new graphical functions;
- interaction improvements.

## Compatibility

The historical document does not define a complete compatibility matrix or migration mechanism.

Future versioning specifications must define:

- version identifiers;
- compatibility rules;
- dependency declarations;
- activation conditions;
- rollback;
- coexistence of versions.

## Consensus

The historical source requires graphical-engine updates to be accepted through the player-node consensus system.

The Consensus Engine remains authoritative for the detailed update-approval mechanism.
