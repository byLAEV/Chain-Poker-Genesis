# Node Core OS Bootstrap

The Node Core OS Bootstrap is the first terminal entry point for Node Core OS on Linux.

## First-stage responsibility

The bootstrap starts the Python terminal interface and presents the Node Core OS main menu.

Internal functionality for Node Core BIOS, Node Core, and Protocols is intentionally developed as subsequent stages.

## Run

```bash
python3 "Node Core OS/Bootstrap/node_core_os_bootstrap.py"
```
