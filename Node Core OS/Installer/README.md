# Node Core OS Installer

This directory contains the first-stage installer for **Node Core OS**.

## Purpose

The installer prepares a local Node Core OS terminal entry point, installs the Python Bootstrap, and then starts the Node Core OS main menu.

The first stage intentionally has no third-party Python dependencies. The Bootstrap uses only the Python standard library.

## Supported environments

- Linux
- Termux on Android
- Python 3.9 or newer
- `python3` available in `PATH`

No `sudo`, `pip`, or external Python package is required.

## Termux prerequisites

Install the required Termux packages once:

```bash
pkg update
pkg install python git
```

Then clone or update the repository.

From inside the `Node Core OS` directory:

```bash
cd ~/Chain-Poker-Genesis/"Node Core OS"
python3 Installer/install.py
```

The installer automatically starts the Node Core OS Bootstrap after installation.

## Installed entry point

The default installation target is:

```text
~/Node Core OS/
```

The installed structure is:

```text
Node Core OS/
├── Bootstrap/
│   └── node_core_os_bootstrap.py
└── node-core-os
```

To start the menu again later:

```bash
~/Node Core OS/node-core-os
```

Or directly:

```bash
python3 "$HOME/Node Core OS/Bootstrap/node_core_os_bootstrap.py"
```

## Custom installation root

A different installation target may be selected with:

```bash
NODE_CORE_OS_INSTALL_ROOT="$HOME/Node Core OS" python3 Installer/install.py
```

The launcher generated by the installer uses that selected installation root.

## Dependency policy

No external Python library is introduced at this stage.

Required runtime components are:

- Python standard library
- Linux or Termux terminal environment
- standard filesystem access
