# Node Core OS

Structural root for the Node Core BIOS, Node Core runtime, and protocol layer.


## Terminal Installer

The first Linux terminal entry point is `node-core-os-installer.py`.

Run it with Python:

```sh
python3 "Node Core OS/node-core-os-installer.py"
```
