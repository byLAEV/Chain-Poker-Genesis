# Consensus API

Defines the interface consumed by Node Core Consensus.

## Contract

- checkExistence
- checkEligibility
- submitProofOfFunction
- verifyProofOfFunction
- submitPreference
- validatePreference
- collectEvidence
- evaluateConsensus
- getConsensusState
- scheduleActivation
- getParticipationState
- suspendEligibility
- restoreEligibility

This API is exclusively for Node Core infrastructure consensus. It does not expose CPG poker/table consensus.
