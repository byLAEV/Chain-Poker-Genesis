# OpenPGP.js Adapter

Purpose: provide a controlled OpenPGP provider boundary for Node Core cryptographic operations.

Pinned reference: OpenPGP.js v6.3.2 — 7315fc8044e7e41a56e724defae9fe9ba754bffc.

The adapter may expose key parsing/generation, encryption, decryption, signing and verification according to the Node Core cryptographic profile.

OpenPGP.js implementation details remain outside the Node Core API contract.
