# Eligibility

Defines the sequential conditions determining whether a Node Core identity may participate.

## Responsibilities

- Existence verification.
- Protocol eligibility.
- Configuration and version compliance.
- Capability requirements.
- Temporal eligibility.
- Transition to ineligible.
- Recovery requirements.

~~~text
Exists ≠ Eligible
~~~

Eligibility is a protocol state, not an intrinsic property of identity.
