# Node Core Development

This directory defines the controlled development and implementation process for Chain Poker Genesis Node Core.

The plan is implementation-facing: it connects existing specifications, implementation work, automated verification, GitHub Actions, Codespaces, and the final local-readiness gate.

## Authority

The Node Core implementation must remain within the Node Core boundary. CPG Protocol functionality is not implemented as part of this workstream.
