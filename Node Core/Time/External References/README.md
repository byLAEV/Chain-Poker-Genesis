# Node Core Time — External Reference Laboratory

This directory contains pinned Git submodule references to external open-source timing projects for research and implementation comparison.

These references are NOT Node Core implementations and MUST NOT be treated as normative CPG code.

Research domains:
- cryptographic timestamping and OpenTimestamps;
- IANA time-zone database;
- NTP and NTS;
- IEEE 1588 PTP;
- GNSS/PPS/PHC timing;
- atomic-clock holdover and disciplined oscillators;
- open time-server architectures;
- uncertainty-aware time APIs;
- data-center PTP profiles.

Each reference is pinned to a specific commit so the research baseline is reproducible.

Before copying any source code into Node Core, verify the source repository license, copyright requirements, dependency licenses, and compatibility with the Chain Poker Genesis repository license.
