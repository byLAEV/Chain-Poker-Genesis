## Historical definition

The document establishes Chain Poker Genesis by LAEV as a **digital poker protocol**, rather than merely a poker application or program.

Its central distinction is:

- an application is a software product designed to provide a specific poker experience;
- a protocol defines rules, principles, structures, and interaction boundaries from which multiple compatible applications or interfaces may be implemented.

## Historical purpose

The source describes the purpose of Chain Poker Genesis as establishing a digital-poker protocol concept in which poker is understood as a technological ecosystem rather than only an isolated application.

The source therefore establishes the following historical design intentions:

1. define a protocol-level identity for Chain Poker Genesis;
2. separate the protocol concept from any single application;
3. permit multiple implementations, applications, or interfaces;
4. preserve a common set of fundamental principles and rules;
5. establish an independent technological identity for the protocol.

## Historical protocol identity

The source identifies Chain Poker Genesis by LAEV as:
