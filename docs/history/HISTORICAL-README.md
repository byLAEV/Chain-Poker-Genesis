# Historial y Antecedentes — Chain Poker Genesis by LAEV

Este directorio contiene todos los archivos históricos, documentos fuente y especificaciones PDF del proyecto Chain Poker Genesis.

## Propósito

Estos archivos representan:
- Especificaciones históricas del protocolo (versiones 0.0 a 34.0)
- Documentación de motores individuales en formato PDF
- Registros de visión y evolución del proyecto
- Archivos de prueba y evidencia (screenshots, etc.)
