CPG / SPECIFICATION

What is Chain Poker Genesis?

Chain Poker Genesis is an implementation-independent protocol project for progressively formalizing decentralized poker into a precise, testable and interoperable system.

The protocol separates game rules from network behavior, cryptographic verification, event history, state management and settlement. An implementation may change without silently changing the protocol itself.

PROTOCOL PRINCIPLES
  • Deterministic execution
  • Explicit state transitions
  • Cryptographic verification
  • Commitment & reveal
  • Distributed event history
  • Replayable state
  • Modular engines
  • Independent implementations
