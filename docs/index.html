The Protocol

What is CPG?

Chain Poker Genesis is an open, implementation-independent protocol project designed to progressively formalize decentralized poker into a precise, testable and interoperable system.

Its purpose is not merely to build a poker application. The project establishes protocol rules, interfaces, verification mechanisms and deterministic state transitions that independent software teams can implement and test.

Core principles

  • Deterministic execution
  • Peer-to-peer coordination
  • Cryptographic verification
  • Distributed event history
  • Replayable protocol state
  • Modular engines
  • Independent implementations
  • Bitcoin-compatible settlement
