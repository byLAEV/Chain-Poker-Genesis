# Cryptographic Connection Engine — Versioning

**Current historical baseline:** 1.0

## Version 1.0

Version 1.0 is the descriptive baseline recorded by the historical PDF. It defines USB Hardware Wallet / HD Wallet connection, new key generation, existing private-key import, BIP-39 seed import, and seed-phrase restoration.

## Future Versions

Future versions should distinguish functional changes, cryptographic changes, interoperability changes, security changes, storage-format changes, and identity-format changes.

A change to cryptographic identity semantics must not be treated as a cosmetic version update because it may affect identity continuity and compatibility.

## Historical Record Rule

The PDF remains immutable historical evidence of what was described in version 1.0.

Repository specifications may evolve, but they must clearly identify whether a statement is historical, formally specified later, proposed, implemented, or deprecated. This prevents later implementation decisions from being incorrectly attributed to the original 1.0 document.
